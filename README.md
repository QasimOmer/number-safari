# 🌟 Number Safari - 1st Grade Math Adventure! 🚀🎈

An interactive, gamified math learning web application designed for 1st-grade students (ages 5–7). Teaches ascending and descending numbers, Pakistani Rupee currency math, visual difference comparisons, hungry alligator inequality symbols, and Ten-Frame number bonds!

---

## 🎮 Game Modes Included

### 1. 🪜 Step Ladder (Learn Ascending & Descending)
* Interactive vertical towers representing number magnitudes.
* Bunny climbs up (1 ➔ 10) or slides down (10 ➔ 1) with ascending and descending musical pitch synthesizers.

### 2. 🚂 Train Station (Carriage Loading)
* Load cargo crates into train wagons in Ascending or Descending order.
* Train blows whistle *(Toot Toot!)* and zooms across the track when complete!

### 3. 🎈 Balloon Popper
* Floating colorful balloons with numbers.
* Pop balloons in correct sequence into the collection basket with real pop sound effects!

### 4. 🪙 PKR Coin Toy Shop (Currency Math)
* Real Pakistani Rupee currency denominations:
  * **Rs 1 Coin** (Bronze/copper 1 Rupee)
  * **Rs 2 Coin** (Golden brass 2 Rupees)
  * **Rs 5 Coin** (Polished nickel-silver 5 Rupees)
  * **Rs 10 Coin** (Bimetallic golden center + silver ring)
  * **Rs 20** (Emerald green Pakistani currency badge)
* Tap coins to deposit exact change into the digital cash register and collect toys in your backpack shelf!

### 5. ⚖️ How Many Less / How Many More? (Comparison)
* Visual 1-to-1 matching rows (Apples vs Bananas, Frogs vs Ducks, etc.).
* Aligned pairs with green checks; glowing extra items show the difference.
* Explains the arithmetic: e.g., `8 - 5 = 3! There are 3 less bananas!`.

### 6. 🐊 Hungry Alligator (`>`, `<`, `=`)
* Interactive alligator jaws that always chomp towards the bigger number!
* Crunchy "CHOMP!" sound effects and particle crunch animations.

### 7. 🧩 Ten Frame Bonds (Making 10)
* Elementary school standard 10-grid manipulative.
* Visual counters and empty dashed circles so kids can count missing spaces to reach 10.

---

## 📱 Mobile & Tablet Responsive
* Fully responsive layout tailored for mobile phones, iPads, tablets, and desktops.
* Touch-friendly oversized tap targets, smooth horizontal swipeable navigation, and fluid layouts.

## 🔊 Audio & Voice Narration
* **Web Audio API**: Real-time synthesized chimes, pops, alligator bites, coin clinks, and fanfares without external audio file dependencies.
* **Web Speech API**: Spoken voice reading questions, prices in Rupees, and cheerful praises aloud.

## 🚀 Running Locally
```bash
# Clone the repository
git clone https://github.com/QasimOmer/number-safari.git

# Enter the directory
cd number-safari

# Start local server
node server.js
```
Open [http://localhost:3000](http://localhost:3000) in any web browser!
